Install:
1. Extract the ZIP.
2. Copy index.html, css, js and images into:
   C:\Users\weryl\Documents\Northamptonshire-History-Hub
3. Replace the existing files.
4. Open:
   http://127.0.0.1:5500/index.html
5. Press Ctrl + F5.

No image editing is required.
