# Northants History Network homepage

Responsive recreation of the approved heritage homepage mock-up.

## Preview

Open `index.html` directly, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before launch

- Replace placeholder `#` links with final destinations.
- Replace the temporary Explorable Games image when the approved artwork arrives.
- Confirm event dates and links.
- Add image-credit details.
